# Content planning

## When to invoke this skill
Run this skill when any of these are true:
- Jake explicitly asks to flesh out, expand, script, plan, or clarify content
- An inbox item, task, or idea mentions reel, post, video, film, caption, hook, script, newsletter, thread, carousel, podcast, or content
- A task says to make, film, edit, publish, or post content but the execution details are missing
- An idea has a format like reel, video, carousel, post, thread, or newsletter and is still rough

## Purpose
Creative work often stalls because the task is phrased at the wrong altitude. "Film the reel" is not actionable if the concept, beats, and shots are still undefined. The goal of this skill is to turn vague content intent into an execution-ready brief, then make the task list reflect reality.

## Procedure

### Step 1 - Identify the asset
Lock down the basics from the available context:
- Platform or account
- Format
- Intended audience
- Core message or transformation
- Why this piece matters now

If these are partly missing, infer conservatively from the linked idea/task and write the assumptions into notes.

### Step 2 - Build the content brief
Update the idea (or create one) with the planning artifacts needed to execute. The brief should usually include:
- One-sentence promise
- 2-3 hook options
- Clear angle or thesis
- Beat-by-beat outline
- Draft script or talking points
- Shot list / B-roll list
- Visual or location notes
- Caption angle and CTA
- Constraints, props, dependencies, and best filming window

Do not stop at abstract advice. Produce usable language and sequencing.

### Step 3 - Make the task list honest
If there is only a vague execution task, fix it:
- Rewrite the task so it matches the real next action
- Add planning tasks when planning is the blocker
- Add production tasks only after the brief is concrete enough to execute

Good sequence:
1. Draft script
2. Capture A-roll / talking head
3. Capture B-roll
4. Edit cut
5. Write caption and publish

Bad sequence:
1. Film the reel

### Step 4 - Preserve linkage
- Link tasks to the relevant idea or project
- Keep the idea in `developing` while the concept is still being shaped
- Store the script, outline, and shot plan in durable notes so future runs can pick up where they left off

### Step 5 - Log the progress
Use `append_log` when the loop meaningfully sharpened a piece of content, not just when it renamed a task.

## Notes
- Planning is the work when the work is still ambiguous.
- Favor one strong concept made executable over five vague content ideas.
- If a piece still depends on a user taste decision, make the open question explicit in notes instead of pretending the task is ready.
