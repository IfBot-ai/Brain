# Side quests

## When to invoke this skill
Run this skill when any of these are true:
- A task is real but cannot be executed yet because a smaller piece of thinking, research, scripting, setup, or decision is missing
- Jake asks a question that reveals a blocker inside an existing task
- A parent task is too vague to act on honestly
- A linked idea clearly needs a bounded child task before the main task can move

## Purpose
A side quest is not random extra work. It is a tight child task that removes a blocker from a parent task. The goal is to make progress without losing the shape of the bigger job.

## Procedure

### Step 1 - Name the parent and the blocker
State what the parent task is and what specifically is missing:
- Script
- Research
- Decision
- Asset
- Setup
- Clarification

If you cannot name the blocker, you are not ready to create the side quest.

### Step 2 - Create the smallest useful child task
The side quest should be narrow and finishable. It should have a clear done condition.

Good:
- Write the 30-60s script draft
- Pick the planting approach for cucumbers: containers vs second bed
- Outline the launch email in 5 bullets

Bad:
- Figure out everything
- Work on content
- Make progress on project

### Step 3 - Keep the parent honest
Update the parent task notes or linked idea so the system reflects the dependency:
- What the parent is waiting on
- Which child task unblocks it
- Any assumptions made during the split

Do not mark the parent done just because the side quest exists.

### Step 4 - Link the work
Link the side quest to the parent task, idea, or project. The child task should leave the system easier to resume later, not harder.

### Step 5 - Avoid scope explosion
Prefer one side quest. If needed, create at most 1-3 immediate child tasks. Do not manufacture a full project plan when only one blocker matters right now.

## Notes
- A side quest should reduce ambiguity, not create busywork.
- If Jake asks a direct question, answer it through `announce`, then launch the side quest in the same run if it is clearly the next useful move.
